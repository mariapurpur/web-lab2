# To-Do List

Веб-приложение для постановки и выполнения повседневных задач.

## Функционал

- Добавление, удаление и редактирование задач;
- Отметка выполнения задач;
- Поиск по названию;
- Фильтрация и сортировка;
- Сохранение в localStorage;
- Изменение порядка задач перетаскиванием.

## Запуск

Откройте файл `index.html` в браузере, либо запустите сайт через GitHub Pages.

## Содержимое файлов

- index.html — подключение JavaScript
- css/style.css — оформление и адаптивность
- js/app.js — логика приложения
- assets/favicon.svg — иконка сайта
